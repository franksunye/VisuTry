# Framed EWE evidence pack

This is a VisuTry Reference Pilot / Simulation assembled from Framed EWE public retailer sources. It is not a customer implementation, authorized collaboration, live campaign, customer dataset, or claim of Framed EWE business performance.

- `research-snapshot.md` records official sources and the source-fact/operator-enrichment boundary.
- `qa-results.md` records Delivery Factory and quality gates after execution.
- `production-verification.md` records production seed, route, session attribution, Admin and multi-brand boundary evidence after publish.

No real AI generation or shopper face data is stored in this package.
