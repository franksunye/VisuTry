# Community Measurement Specification

## Daily evidence

Each run records start/end time, platform authentication, searches performed, meaningful actions, exact public text, product mentions/links, follow-ups, questions, insights, no-action searches, failures, and Git commit/push outcome.

## Activity metrics

- Meaningful Reddit comments
- Meaningful YouTube comments/replies
- Follow-ups completed
- Original Reddit posts
- Search queries and communities reviewed

## Quality metrics

- Replies received
- Conversations with more than one exchange
- Tool requests
- Constructive/negative responses
- Removals, mod friction, rate limits, or account-health signals

## Promotion metrics

- VisuTry mentions
- VisuTry links
- Percent of public interactions with neither mention nor link over a rolling 30 days

## Research metrics

- Unique user questions
- Repeated questions
- SEO candidates
- Visual SEO candidates
- Consumer, Advisor, Try-On, Compare, Store, Merchant, FAQ, and content insights

## Attribution

Use existing analytics only when available. Record referral sessions, landing-page visits, signups, detector use, try-ons, and purchases by Reddit/YouTube where the repository's current analytics can support it. If attribution is weak, document the gap. Never invent referral evidence.

## Weekly interpretation

Do not conclude that a channel works or does not work from a few days. Compare several weeks of useful interactions, reply quality, questions, promotion ratio, and measurable product/traffic signals.
