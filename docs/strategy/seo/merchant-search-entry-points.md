## Baseline and measurement

- Historical anchor, 17 October–13 November 2026 inclusive. GSC Web reported 32 impressions and zero clicks for paths containing `/business`, all on the English Business homepage. The 16 exact landing pages have a different scope. No rows were returned for these 16 in that GSC window, including the returns article when queried explicitly. Report missing rows and unpublished URLs separately.
- In the same window GA4 property `AI-2024 / visutry.com` reported 31 sessions landing on paths containing `/business`. Session source/medium included 5 Bing organic, 1 Google organic, 1 ChatGPT AI-assistant on Platform, and 5 explicitly identified release-testing sessions. Four of the Bing sessions landed on Pilot, which is in this portfolio. Retain the historical site-section baseline separately from the exact 16-URL cohort.
- Record the first verified production www HTML for each changed URL. Check real Google index status and last crawl, then use the first complete seven days for preliminary signals and a full post-crawl 28-day window for evaluation. Compare existing owners against an equal pre-release window. Report first discovery for new URLs, with no invented pre-release rate.
- Weekly GSC Web: exact page totals, newly visible nonbrand buying queries, country/device, impressions, clicks, CTR and position. Read the full query set as well as these example questions. Track overlapping phrases against all landing pages before assigning an owner. Query detail may omit anonymized searches.
- Weekly GA4: exact landing path, sessions and session source/medium. Report organic search and identifiable AI-assistant referrals separately. Exclude identifiable QA/internal traffic. Unknown sources and mixed-intent blog visits stay labeled. Avoid deriving visitor identity from the landing page or attributing all article visits to optical merchants.
- For generative discovery, record platform, language, region, question, date, exact cited URL and reproducible evidence. Fix platform and locale for repeat runs and rotate the questions across the weekly checks. Record inaccessible answers as unknown. Google generative impressions, observed citations, and identifiable visits are separate measures.
- A first qualified click or AI referral is an initial signal. Five relevant nonbrand clicks for a theme across at least two weeks is a working threshold for deeper coverage. Use recrawl timing, traffic volume and query fit when the threshold is unmet. Multiple themes shipped together, so this is an acquisition trial without causal A/B attribution.
